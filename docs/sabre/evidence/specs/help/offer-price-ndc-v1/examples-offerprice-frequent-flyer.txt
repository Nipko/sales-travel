OfferPrice Frequent Flyer

Frequent Flyer Request

Scenario

The Frequent Flyer example presents a use-case with passenger details required for frequent flyer processing. This type of information must be provided within the passengers array.

Instruction

To send a frequent flyer request, we need to provide the following information:

Property |
Description |

query.offerItemId
 |
The ID of an offer item selected from a shopping response.
 |

passengers.id
 |
The unique ID of a passenger. Should be the same as the one returned in an earlier shopping step.
 |

passengers.personName.givenName
 |
The given name of a frequent flyer passenger.
 |

passengers.personName.surname
 |
The surname of a frequent flyer passenger.
 |

passengers.frequentFlyer.airline
 |
The IATA carrier designator code.
 |

passengers.frequentFlyer.accountNumber
 |
The loyalty program account number.
 |

Example Value

{
  "query": [
    {
      "offerItemId": [
        "ce5b4fd69b46x4qh9lrrr5ihh0-1-1"
      ]
    }
  ],
  "passengers": [
    {
      "id": "Passenger1",
      "personName": {
        "givenName": "JORDAN",
        "surname": "LOYTEST"
      },
      "frequentFlyer": [
        {
          "airline": "VA",
          "accountNumber": "123456789"
        },
        {
          "airline": "QF",
          "accountNumber": "1380227"
        }
      ]
    }
  ]
}

Frequent Flyer Response

Summary

As a response to our Frequent Flyer request, the API returned a priced offer with the requested frequent flyer information contained within the frequentFlyer array.

Next Steps

The Offer Price API is the second step in the New Distribution Capability (NDC) Workflow. Go to the NDC Workflow Guide for more information.
