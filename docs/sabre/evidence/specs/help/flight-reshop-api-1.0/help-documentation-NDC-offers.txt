NDC Offers

 |

Requires NDC content to be activated for the PCC.
 |

Overview

This capability returns NDC exchange shopping content in the Sabre Flight Reshop response.

Use this capability to:

request exchange offers from the NDC distribution source.

consume NDC-specific offer behavior while keeping a consistent Flight Reshop response structure.

Recommended handling:

Handle NDC offers and ATPCO offers separately based on FlightReshopResponse.offers.source.distributionModel.

Evaluate FlightReshopResponse.offers.isSellable before booking.

If FlightReshopResponse.offers.isSellable is true, proceed with rebooking.

If FlightReshopResponse.offers.isSellable is false, treat the response as informational and call offers/reshop/price before booking.

For NDC offers, airline-supplied content is returned and the response reflects the carrier's available data.

 |

Some offer properties are not returned for NDC offers.
 |

Requesting NDC offers

Use the standard Flight Reshop request format and set the distribution source to NDC.

Parameter |
Description |
Sabre Flight Reshop Path |

distributionModel
 |
Identifies the downstream distribution source to use for exchange shopping. For this feature, set the value to NDC.
 |
FlightReshopRequest.source.distributionModel
 |

Response with NDC offers

For NDC distribution source, the response includes offer and offer item data from the downstream NDC exchange shopping response returned from the carrier.
