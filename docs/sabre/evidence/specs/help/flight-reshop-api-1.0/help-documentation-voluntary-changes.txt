Fee Flexibility and Refundability Information (Voluntary Changes)

This API functionality allows you to retrieve information about maximum and minimum fees for changes and refunds. It's also possible to search for fares within a specific fee limit.

 |

The Sabre system uses this information to determine the feasibility and cost of voluntary changes. However, the availability of a change is not guaranteed, even if the data suggests a cost. Carrier rules and other restrictions may prevent a change due to the lack of actual new itinerary, despite penalty details being returned.
 |

Penalty information source

To determine penalties, Sabre primarily uses Automated Categories 31 (Voluntary Changes) and 33 (Voluntary Refunds). If a carrier doesn't provide this information (Categories 31 and 33 are missing), Sabre assumes that changes and refunds are free as per the ATPCO system assumption.

Maximum penalty calculation

The API calculates the maximum penalty by considering all possible combinations of all changed fare components (Record 3s) and returning the highest penalty according to the instructions from Categories 33 or 31, regardless of restriction date ranges.

Exceptions:

Totally Non-Refundable or Non-Changeable: If all combinations indicate a fare is non-refundable or non-changeable, those combinations are ignored if at least one combination allows a refund or change.

Example From Category 31 Coding: The API interprets rules provided by the carrier (such as those in Category 31) to determine penalties. These rules may be interpreted as shown in the following examples:

Example 1 (With Fee): &#8220;CHARGE USD 170.00 FOR REISSUE OR HIGHEST FEE OF ALL CHANGED FARE COMPONENTS…&#8221; indicates a potential fee.

Example 2 (No Change Allowed): &#8220;CHANGES NOT PERMITTED TO THE FARE COMPONENT&#8221; is a non-changeable indication.

Example 3 (A Single Fare With Two Conditions):

With Fee: &#8220;CHARGE USD 170.00 FOR REISSUE OR HIGHEST FEE OF ALL CHANGED FARE COMPONENTS…&#8221; indicates a potential fee.

No Change Allowed: &#8220;CHANGES NOT PERMITTED TO THE FARE COMPONENT&#8221; is a non-changeable indication.

 |

Such a combination results in a fee.
 |

Only Non-Refundable Combination: If only one combination exists and it states that all fare components are non-refundable, the API responds that the entire ticket is non-refundable.

Minimum penalty calculation

The minimum penalty assumes only the cheapest fare component is changed.

Requesting information on Voluntary Changes

The following parameters can be used to request voluntary changes for new offers:

Parameter |
Description |
Sabre Flight Reshop Path |

returnOfferAttributes
 |
