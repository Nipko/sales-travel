Fulfill Flight Tickets – Examples

Below are some common use cases for using the Fulfill Flight Tickets method to fulfill a booking.

Traditional ATPCO booking fulfillment based on PQ data and with PAYMENTCARD form of payment

To ensure the successful fulfillment, your request should contain the following information:

confirmationId (PNR Locator).

Supported form of payment data inside the formsOfPayment object.

fulfillments details with required ticketingQualifiers and a form of payment selected (the payment parameter).

Necessary printers within the designatePrinters array.

{
  "confirmationId": "ABCDEF",
  "fulfillments": [
    {
      "ticketingQualifiers": {
        "priceQuoteRecordIds": [
          "1",
          "2"
        ]
      },
      "payment": {
        "primaryFormOfPayment": 1
      }
    }
  ],
  "designatePrinters": [
    {
      "hardcopy": {
        "address": "B18BG1"
      }
    },
    {
      "ticket": {
        "countryCode": "AT"
      }
    }
  ],
  "formsOfPayment": [
    {
      "type": "PAYMENTCARD",
      "cardTypeCode": "VI",
      "cardNumber": "4487971000000006",
      "expiryDate": "2025-07"
    }
  ]
}

A successful operation results in no errors. In this scenario, a normalized tickets array containing the issued documents is returned in the response and stored in the booking:

Traditional ATPCO booking and ancillary fulfillment (EMD issuance) with PAYMENTCARD form of payment

confirmationId (PNR Locator).

Supported form of payment data inside the formsOfPayment object.

fulfillments details with the IDs of each ticket and EMD (within the ancillaryIds array) and a form of payment (the payment parameter).

 |

The ID of an ancillary is returned as the itemId in the Get Booking response.
