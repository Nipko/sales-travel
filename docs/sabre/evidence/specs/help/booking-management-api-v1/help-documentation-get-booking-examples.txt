Get Booking – Examples

Request

The Get Booking endpoint for accessing the RPC/JSON version is:

POST /v1/trip/orders/getBooking HTTP/1.1

The call to Get Booking via RPC/JSON must contain at least one value: confirmationId.

This will return a response with all data related to confirmationId. You can also filter the response using returnOnly, which is provided as an array of values. Refer to the schema for a full list of accepted enumerators.

{
  "confirmationId": "XXXX"
}

In general, GetBooking takes the latest ticket status into consideration and limits the number of ticket entries in the response. However, since the refund operation for conjunctive tickets generates a TR item (stored in the booking) with just the primary document, both the TR item ("number": "1609786952746") and the original TE item ("number": "1609786952746/47") are returned in the response.
