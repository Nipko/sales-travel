Refund Flight Tickets – Examples

Below are some common use cases on how to refund flight tickets:

Refund a single document

To ensure a successful refund of the requested document, add the following parameters to your request:

tickets

number (a 13-digit electronic document number)

{
  "tickets": [
    {
      "number": "1607531707951"
    }
  ]
}

Refund a conjunctive document

To ensure a successful refund of the requested document, add the following parameters to your request:

tickets

number (a full conjunctive document number or a 13-digit electronic number of the main document)

{
  "tickets": [
    {
      "number": "1606802005012/13"
    }
  ]
}

or

{
  "tickets": [
    {
      "number": "1606802005012"
    }
  ]
}

Refund all documents of a booking

To ensure a successful refund of all documents in a booking, your request should contain:

confirmationId

{
  "confirmationId": "ABCDEF"
}

Refund all EMD documents for a booking

To ensure a successful refund of all EMDs in a booking, your request should contain:

confirmationId

documentsType

{
  "documentsType": "EMDs",
  "confirmationId": "GHIJKL"
}

Refund two documents, change context, and designate ticket printer

To ensure a successful refund of the requested documents, switch from the current Pseudo City Code (PCC) to the target PCC where the transaction should be executed and use a specific printer. Your request should contain:

tickets

number (a 13-digit electronic document number)

targetPcc (the PCC where the void transaction of the ticket should be executed)

designatePrinters

ticket

address (the LNIATA address of the printer)

countryCode

{
  "targetPcc": "7KFA",
  "tickets": [
    {
      "number": "0143357868284"
    },
    {
      "number": "0143357868285"
    }
  ],
  "designatePrinters": [
    {
      "ticket": {
        "address": "EF34GH",
        "countryCode": "RU"
      }
    }
  ]
}

Refund multiple documents and define refund qualifiers

To ensure a successful refund of multiple documents, including refund qualifiers, add the following parameters to your request:

tickets

number (a 13-digit electronic document number)

refundQualifiers, for example:

waiverCode

overrideCancelFee

commissionAmount

{
  "tickets": [
    {
      "number": "6077531707952",
      "refundQualifiers": {
        "waiverCode": "ABCD1234",
        "commissionAmount": "25.00"
      }
    },
    {
      "number": "6077531707953",
      "refundQualifiers": {
        "overrideCancelFee": "0.00",
        "commissionAmount": "15.00"
      }
    }
  ]
}

 |

By defining refund qualifiers, you will override Sabre system pricing. Use at your own risk.
 |

Refund multiple EMDs and specify commission qualifiers

To ensure a successful refund of multiple EMDs, including commission qualifiers, add the following parameters to your request:

tickets:

number (a 13-digit electronic document number)

refundQualifiers, for example:

commissionAmount

commissionPercentage

{
  "documentsType": "EMDs",
  "tickets": [
    {
      "number": "0451826838118",
      "refundQualifiers": {
        "commissionAmount": "25.00"
      }
    },
    {
      "number": "0451826838119",
      "refundQualifiers": {
        "commissionPercentage": "2"
      }
    }
  ]
}

To execute the check flight ticket operation, determine the desired document numbers and applicable refund qualifiers.

For example, a request to refund all documents could be:

{
  "tickets": [
    {
      "number": "6077531707952",
      "refundQualifiers": {
        "waiverCode": "ABCD1234",
        "commissionAmount": "25.00"
      }
    },
    {
      "number": "6077531707953",
      "refundQualifiers": {
        "overrideCancelFee": "0.00",
        "commissionAmount": "15.00"
      }
    }
  ]
}

In this example, we specified different qualifiers for each ticket:

6077531707952

waiverCode applies the waiver code as provisioned by the issuing carrier

commissionAmount applies the commission you received for this refund

6077531707953

overrideCancelFee is set to the cancel fee

commissionAmount applies the commission you will receive for this refund

overrideTaxes applies refundable amounts for specific taxes

 |

By defining refund qualifiers, you will override Sabre system pricing. This is at your own risk.
